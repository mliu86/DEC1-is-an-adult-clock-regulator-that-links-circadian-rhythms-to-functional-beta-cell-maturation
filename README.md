# DEC1 is an adult clock regulator that links circadian rhythms to functional beta-cell maturation

This repository contains custom R scripts for single-cell RNA-seq and ATAC-seq analyses associated with the manuscript.

## Repository Contents

### Single-cell RNA-seq (`scRNA_seq/`)

- `sc_RNA_v9.R` — Single-cell RNA-seq analysis.
- `Cellchat.R` — Cell-cell communication analysis using CellChat.
- `DEC1_Beta1_Beta2.R` — Analysis of beta-cell subpopulations.

### Single-cell ATAC-seq (`scATAC_seq/`)

- `atac_v8.R` — Single-cell chromatin accessibility analysis.

## Experimental Groups

Pancreatic islets from wild-type and Dec1 knockout mice were analyzed using single-cell transcriptomic and chromatin accessibility approaches.

## Data Availability

The associated sequencing datasets are deposited in the NCBI Gene Expression Omnibus (GEO). Accession numbers will be added upon release.

## Code Availability

The custom R scripts used for single-cell RNA-seq and ATAC-seq analyses are publicly available in this repository.
